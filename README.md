## 📱 Introduction

**DOF3TNA v1** is an Android application designed for **first-year students at the Faculty of Commerce - Alexandria University**. The app provides a comprehensive platform to organize lectures, access educational materials, and manage schedules with ease.

---

## 🚀 Features

- **Lecture Organization**: Organize lectures by subjects and types.
- **Educational Resources**: Access materials like slides, summaries, and videos.
- **Schedule Management**: View and manage class schedules.
- **Offline Support**: Works offline for better accessibility.
- **Fast and Lightweight**: Optimized for speed and performance.

## 📱 مقدمة

**DOF3TNA v1** هو تطبيق أندرويد مصمم لدعم **طلاب الفرقة الأولى بكلية التجارة - جامعة الإسكندرية**. يقدم التطبيق منصة شاملة لتنظيم المحاضرات والوصول إلى المصادر التعليمية وإدارة الجداول الدراسية بكل سهولة.

---

## 🚀 المميزات

- **تنظيم المحاضرات**: تنظيم المحاضرات حسب المواد وأنواعها.
- **المصادر التعليمية**: الوصول إلى المواد التعليمية مثل الشرائح، الملخصات، والفيديوهات.
- **إدارة الجدول الزمني**: عرض وإدارة جداول المحاضرات.
- **دعم العمل دون إنترنت**: يعمل التطبيق دون الحاجة للإنترنت لتسهيل الوصول.
- **سريع وخفيف**: تم تصميم التطبيق ليتسم بالسرعة والأداء الممتاز.
